## ✨ About

An interactive quiz web application built with pure HTML, CSS, and JavaScript. Users can answer multiple choice questions and get their score at the end.

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| 🌐 HTML | Structure |
| 🎨 CSS | Styling |
| ⚡ JavaScript | Logic & Interactivity |
| 📦 GitHub Pages | Deployment |

---

## 🎯 Features

- ✅ Multiple choice questions
- ✅ Score tracking system
- ✅ Result display at the end
- ✅ Clean and simple UI
- ✅ No frameworks — pure vanilla JS
- ✅ Fully Responsive design
